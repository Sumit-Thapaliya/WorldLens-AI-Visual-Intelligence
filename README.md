# 👁️ WorldLens

> **A pocket AI that can see and understand the world through your camera.**

WorldLens is an on-device AI reality scanner. Point your phone at the world and get real-time object detection, tracking, counting, scene understanding, voice interaction, and AR-style labels — everything runs on the phone, no internet required.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎯 **Real-time detection** | 80 common objects (COCO classes) detected live from camera |
| 🔢 **Counting & tracking** | Stable object IDs across frames; accurate per-class counts |
| 🔎 **Find Object mode** | Search for an object by typing or voice; app highlights it and tells you where |
| 📍 **Spatial awareness** | Approximate direction (left/right) and distance |
| 🏠 **Scene understanding** | Classifies kitchen, office, street, park, classroom, etc. |
| 🎤 **Voice interaction** | "What do you see?", "Find a bottle", "How many people?" |
| 🏷️ **AR-style labels** | Bounding boxes + confidence scores overlaid on camera |
| 📴 **Offline & private** | All AI runs on-device; no data leaves your phone |

## 🏗️ Architecture

- **React Native + TypeScript** — UI, screens, navigation, hooks, detection overlay, state management
- **Kotlin (Android native)** — CameraX integration, ONNX Runtime inference, SpeechRecognizer/TTS, optional native tracker
- **Python (dev-time only)** — Model selection, evaluation, quantization, ONNX conversion
- **Pretrained model** — SSDLite MobileNetV3-Large (COCO, 80 classes), ~12 MB, INT8 quantized for mobile
- **Runtime** — ONNX Runtime Mobile with NNAPI/GPU acceleration
- **No backend, no database, no custom training**

```
Camera ─► CameraX ─► ONNX inference ─► Tracker ─► Overlay/Voice/Scene/Find
                │                                  ▲
                └──────── React Native UI ─────────┘
```

See [`docs/architecture.md`](docs/architecture.md) for details.

## 🚀 Getting Started

### 1. Prepare the AI model (Python)

```bash
cd ai/
pip install -r requirements.txt
python scripts/convert_model.py --model ssdlite --output ../mobile/assets/models/object_detector/
```

This downloads the pretrained SSDLite MobileNetV3-Large model and exports it to ONNX with INT8 quantization for mobile deployment.

### 2. Run the mobile app (Android)

```bash
cd mobile/
npm install
# Ensure an Android emulator or device is connected
npm run android
```

### 3. Web preview (for UI development without Android toolchain)

Open `preview/index.html` in a browser to see an interactive mock of the scanner UI that simulates detections using the same tracking/counting/voice logic.

## 🧠 Model Choice

**SSDLite MobileNetV3-Large (320×320)** is the default — it strikes the best balance of:
- Small size (~12 MB INT8)
- Real-time CPU inference (15-30 FPS on mid-range Android)
- 80 common COCO object classes (person, car, bottle, chair, dog, phone, laptop, etc.)

YOLOv5n is also supported via the Python conversion script if you prefer it.

## 🎙️ Voice Commands

- `"What do you see?"` — Lists detected objects
- `"How many people are there?"` — Counts specific objects
- `"Find a bottle."` — Enter find mode for the target object
- `"Where am I?"` — Describes the current scene
- `"Stop."` — Cancel current search

## 🔒 Privacy

WorldLens is designed with privacy as a default:
- All inference runs locally on the device
- No camera frames, audio, or detection results are sent to any server
- No account required
- No analytics in v1
